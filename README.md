# Kütüphane Takip Sistemi 

C# Windows Forms ve SQL Server kullanılarak geliştirilmiş, bir kütüphanenin kitap, üye ve ödünç alma süreçlerini dijital ortamda yönetmesini sağlayan bir masaüstü otomasyon projesidir.

---

## Özellikler

* **Üye Yönetimi:** Üye ekleme, silme, güncelleme ve listeleme işlemleri.
* **Kitap Yönetimi:** Kitap kayıtlarının tutulması, yazar gibi bilgilerin takibi.
* **Ödünç Alma Sistemi:** Hangi üyenin hangi kitabı, ne zaman ödünç aldığının ve teslim ettiğinin takibi.

---

## Kullanılan Teknolojiler

* **Geliştirme Ortamı:** Visual Studio 2026
* **Programlama Dili:** C#
* **Arayüz Teknolojisi:** Windows Forms App (.NET Framework)
* **Veritabanı:** Microsoft SQL Server (MSSQL)
